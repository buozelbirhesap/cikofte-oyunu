Oyunumuz Mehmet Usta Çiğ Köfte Diyarında, Mehmet Usta'nın çiğ köfte yapmak için gereken malzemelerini toplama hikayesini ele alır. 
Lakin Urfalı Mehmet ustanın bu malzemelere ulaşması pek kolay olmayacaktır. 
Zorlu parkurları aşacak, Japon kültürün temel taşlarından olan suşilere basmayacak günün sonunda hedeflediği malzemeye ulaşacak. 
Bu parkurların bitiminde Urfalı Mehmet Usta, ulaşmak istediği çiğ köfte dürümüyle kavuşacak. 
Ve siz oyuncu Mehmet Usta'nın bu macerasına eşlik edip onun dürümüne kavuşmasını sağlayacaksınız.
